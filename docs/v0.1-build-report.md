## 验收中抓出并修掉的三个真 bug

1. **durable user content 是裸 string**（`submissions.ts:201` 直写 `draft.content`）→ stable 生态全按数组处理，powerline 的 last-request 扫描直接miss。修：adapter + rebuild 双路归一化为 `[{type:"text"}]`（`normalizeUserMessage`）。
2. **pi.system 定位提示被透传成 system 消息 entry**：污染 branch 统计（💬 虚增）、与 rebuild 路径不一致（resume 后计数漂移）。修：adapter 丢弃 system 角色消息（stable 本就从不把 system 消息当 agent 事件发）。
3. **compact 失败静默**：stable /compact 处理器吞 throw、只认 `compaction_end{errorMessage}` 事件；facade 原来在发 start 之前就 throw。修：对齐 base 顺序（先 start，失败路径发 end+errorMessage 再 rethrow）。
